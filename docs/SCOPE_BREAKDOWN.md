# Scope Breakdown

## Layer 0: Foundation

- Confirm product brief.
- Define core users and workflows.
- Decide backend API boundaries.
- Decide mobile navigation shape.
- Scaffold runnable Expo and NestJS app code when ready.

## Layer 1: First Vertical Slice

- Implement one backend resource.
- Add validation and tests for the resource.
- Connect one mobile screen to the backend endpoint.
- Verify local development flow end to end.

## Layer 2: Product Expansion

- Add remaining core flows.
- Add authentication if needed.
- Add persistence and deployment configuration.
- Add CI checks for both workspaces.
