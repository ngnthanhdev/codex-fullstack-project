4. Chon approach mac dinh neu user khong yeu cau khac.
5. Cap nhat `docs/SCOPE_BREAKDOWN.md` neu scope thay doi.
6. Tao/cap nhat task trong `tasks/layer-*-todo.md`.

- Design note ngan trong chat hoac docs.

- Khong code feature lon khi spec con qua mo.
